# Changelog

This file records public package changes. Source development may move ahead of
the latest published package; test results from a private checkout are not
release claims.

## 0.1.0-beta.1

First Workkeel beta prerelease. It introduces the native task contract and
lifecycle, source and package CLI, optional local observer, and explicit
compatibility path for existing Temple projects. See the
[quick start](docs/getting-started/workkeel.md) and
[migration guide](docs/getting-started/migration-from-temple.md).

Earlier Temple alpha history belongs to the legacy compatibility line. The
retained compatibility code and fixtures are not a promise that every old
project has been migrated.
