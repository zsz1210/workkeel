# Views

Files in this directory are generated projections. Rebuild `status.md` and `capabilities.json` with `temple status`. Generate `parallel-plan.json` with `temple parallel plan`; rebuild it whenever status or a Context Capsule reports that it is stale. Generate a scoped work-item capsule with `temple context resolve --work-item WI-####`. Do not edit a view as the only copy of a decision.
