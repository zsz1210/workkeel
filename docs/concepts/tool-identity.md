# Execution tool identity

The collaboration scene identifies a product from its reported `tool` field.
Agent, activity, provider, selected model and reported model are separate facts.
An Agent named Claude or a model from OpenAI does not prove that Claude Code or
Codex executed the work.

The registry recognizes explicit Codex and Claude Code identifiers. Other tools
use a neutral mark and their reported name. Multiple tools remain multiple
executors; missing tool identity stays unknown. Failed images fall back to the
neutral mark while retaining the product name.

The scene emphasizes one current or latest activity, compact recent records and
expandable older history. Only explicitly queued activities appear as pending.

non-overlapping intervals and means time order, not a confirmed Agent handoff.
Review and acceptance remain separate recorded facts.
