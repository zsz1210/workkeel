# ADR-0059: Proportionate work routes and stage completion

Status: Accepted for implementation; independent validation pending.

## Decision

The maintainer approved separating ordinary delivery, bounded read-only assistance and governed parallel delivery. Preserve native instructions, bootstrap, current authority and revision checks. Route procedures by the requested operation instead of treating project records as a universal reading checklist.

A parent may delegate bounded read-only assistance when runtime delegation is authorized. This is not a worker kind or lifecycle participant. The parent retains responsibility and integrates findings; a helper cannot claim acceptance or formal QA. Project/canonical writes, independent delivery, formal verification responsibility, scarce shared resources, external actions, unclear scope or independently recoverable ownership require the existing governed route. Never reclassify active workers to evade claims or reservations.

Sequential delivery does not require a parallel plan. Governed dispatch retains plan, prepare, attachment and join. Complete the current stage, not downstream responsibilities. Successful composed finish diagnostics satisfy their own checks only for unchanged verified scope; failures and historical receipts are not fresh acceptance.

## Limits and validation

This is an instruction contract, not sandbox enforcement or proof of model adherence. Use native read-only restrictions where supported; do not dispatch if the boundary cannot be maintained. Static contract and distribution tests do not establish efficiency or Independent QA.

Retain ADR-0057/0058 implementation. No runtime guards, model policy, required tests, profiles, initialization naming or experiment protocols change. Update framework sources; installed managed copies change only through reviewed upgrade, not hand-edited locks.
