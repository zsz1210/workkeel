# ADR-0062: Compact operating instructions

Status: accepted for bounded implementation and comparison qualification; no measured efficiency claim.

## Decision

Keep the four existing entrypoints. AGENTS routes work; the whole TEMPLE contract
owns authority and conditional obligations; the Work Skill owns lifecycle mechanics;
its Lean reference owns the eligible claim/finish recipe. Remove repeated prose
and repeated reporting requirements, not authority, required reads or verification.
One substantive evidence record can support multiple gates by reference. The
existing one-finish command and unchanged-state diagnostics reuse are not new savings.

No Position, workflow, router, memory cache, provider, schema or mandatory command is
added. Native/project instructions and required whole/nested/unselected sources
remain required. A digest is not proof of reading. Standard and High-Assurance keep
their gates; ordinary Lean keeps a distinct Verifier. Specialized existing procedures
are read when triggered, never silently waived for small tasks.

## Ownership and migration

Author distribution sources in `project-overlay/`. Supported upgrade installs the
three managed bodies and updates exact lock entries. AGENTS is project-owned;
upgrade preserves it. A maintainer may explicitly reconcile its marked section,
preserving all unrelated instructions. Existing installations retaining an older
AGENTS contract must obey it; no automatic savings claim applies to them. Init
still preserves/imports native entrypoints and reports unresolved bootstrap.

## Qualification and limits

Qualification maps retained obligations and checks real installation, upgrade, claim,
finish and negative controls. A future six-subject diagnostic compares ordinary,
previous Temple and compact Temple in stable/changed-spec conditions. Previous
instruction bytes are pinned to `4c606f7113600caeec04daf29477daa17b07409c`;
runtime code, product facts, model, request and current evaluator are held constant.
Only four distribution files may differ between runtime bundles. No historical
result is rescored or pooled. Source/JSON byte counts are not Token measurements.

Quality, administration, complete-attempt Tokens and elapsed time remain separate.
One sample per condition/treatment is diagnostic, not a statistically established
effect. Qualification performs no model generation; the new frozen protocol needs
its own explicit execution authority. No retry, fallback or automatic budget reset.
Revert this instruction treatment if authority or acceptance regresses; preserve
old evidence and inspect in-flight recovery before changing installed instructions.
